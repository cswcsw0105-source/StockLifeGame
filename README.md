# 스톡라이프 리그

브라우저에서 실행되는 턴제 주식 게임입니다. 로컬 테스트는
`python3 -m http.server 8000`을 실행한 뒤 http://localhost:8000 에서 합니다.

기업 이름과 뉴스 문구는 `content.js`에서 관리합니다. 진행 중인 시즌을
이어 쓰려면 종목 코드와 뉴스 순서를 유지하세요.

매수·매도는 수수료 없이 즉시 체결됩니다. 다음 턴을 누르면 시장이 진행됩니다.
현재 자산으로 결과 보기를 선택하면 시즌을 조기 정산합니다.
진행 기록은 쿠키에 저장하고, 길어지면 브라우저 로컬 저장소를 함께 사용합니다.
